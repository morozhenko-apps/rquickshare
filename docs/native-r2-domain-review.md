# Download origin contract

The accepted production download origin and product prefix remain fixed by the flat distribution contract. Existing sibling products share that origin. Never repoint DNS or recreate the old per-product Worker/bucket design as a cleanup action.

See [current distribution](FLAT_DISTRIBUTION.md), [tagged release](native-tagged-release.md),
[local signing](native-local-signing.md), [encrypted recovery](native-signing-backup.md)
and [bounded source CI](ci-pilot.md).

[Original design and observations](https://github.com/morozhenko-apps/rquickshare/blob/ed0a626807711008e6ed4ddeb8bdcef564f58d59/docs/native-r2-domain-review.md) remain in Git history.
Concrete provider identifiers, private locations, grant inventories and
chronological operator receipts are not current public instructions.
