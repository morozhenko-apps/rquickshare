# Retired download Worker route

The dedicated download Worker was retired for the accepted direct R2 flat channel. Do not recreate its route, binding or build integration from old observations. Public GET/HEAD, Range, ETag and metadata freshness remain delivery contracts; CDN configuration is independently owned.

See [current distribution](FLAT_DISTRIBUTION.md), [tagged release](native-tagged-release.md),
[local signing](native-local-signing.md), [encrypted recovery](native-signing-backup.md)
and [bounded source CI](ci-pilot.md).

[Original design and observations](https://github.com/morozhenko-apps/rquickshare/blob/ed0a626807711008e6ed4ddeb8bdcef564f58d59/docs/native-download-route.md) remain in Git history.
Concrete provider identifiers, private locations, grant inventories and
chronological operator receipts are not current public instructions.
