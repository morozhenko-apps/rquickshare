# rQuickShare engineering state

Current priorities and unresolved problems are tracked in [active development Issues](https://github.com/morozhenko-apps/rquickshare/issues) and the [active backlog](active-backlog.md).

The native Linux client combines a sharing core, user-session service and GTK desktop interface. It supports nearby discovery, explicit incoming consent, transfer status and desktop integration. Network admission, authenticated peer identity, interruption/cancellation, file ownership and native UI behavior remain independently verifiable concerns.

Automated source checks, real Android/Linux transfers, native package installation and signed release distribution are **different evidence classes**. A passing test or old demonstration does not establish complete device interoperability. Older version-specific studies and exact test transcripts remain in Git history and the linked, dated engineering documents.

Do not append terminal transcripts, CI polling updates or per-commit status notes here. Use issue-specific tracking and the code/test history for that purpose.
