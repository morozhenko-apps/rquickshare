# APT publication decision reference

Signed flat distribution is implemented and the accepted Native 1.0.0-1 publication remains immutable. Previous initial-hosting/custody choices are historical; publication still requires owner approval and independent source, signature, public-byte and installed-client evidence.

See [current distribution](FLAT_DISTRIBUTION.md), [tagged release](native-tagged-release.md),
[local signing](native-local-signing.md), [encrypted recovery](native-signing-backup.md)
and [bounded source CI](ci-pilot.md).

[Original design and observations](https://github.com/morozhenko-apps/rquickshare/blob/ed0a626807711008e6ed4ddeb8bdcef564f58d59/docs/native-apt-publication-review.md) remain in Git history.
Concrete provider identifiers, private locations, grant inventories and
chronological operator receipts are not current public instructions.
